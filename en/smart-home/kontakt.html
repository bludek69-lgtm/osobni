The purpose of the website

Stack

  • Homey Pro 2026
  • HomeyScript (JavaScript runtime)
  • Local SSD logging (JSONL + SQLite) on Raspberry Pi (primary source of events from 27.5.2026); Google Sheets just an archive history layer, no longer an active pipeline
  • Home Assistant OS (mirror + observer)
  • Gemini API (Daily Diagnostics)
  • HTML/CSS/JS dashboards
  • GitHub as a single source of truth
