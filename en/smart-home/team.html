Who is worth it SMART HOME OS

It is not a one-man project. Nor is it a single AI project. It is collaboration between a human and several AI layers — each plays a clearly delineated role and each adds something they couldn't do alone.

Human + AI Co-Built System

Architecture of collaboration

Pipeline ideas → code → system

Each role has a clear handoff to the next one. Idea travels from top to bottom, runtime feedback travels back to top.

Luděk · Architect Defines use-case, priority, acceptance criteria. Real experience with the system.
ChatGPT · Architectural Co-Pilot Audit of the current state, architecture design, identification of what can be done better.
Claude Code + Cody · Engineering They write code, deploy via API, test, document. Concrete implementation of the proposal.
Homey Pro 2026 · Runtime 84 devices, 145+ scripts, 248+ flows. Physical reality — lights, heating, audio, sensors.
Gemini · Embedded AI Layer Observes traffic, diagnoses, briefs. The layer between the system and the user.

Principle

Why it works

None of those AIs would build the system by themselves. ChatGPT can schedule but not deploy the script. Claude Code can implement, but needs clear input. Gemini can diagnose but cannot design architecture. The human architect holds together intent, priority, context. AI layers speed up his every step by 10x.
