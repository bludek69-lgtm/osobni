🏠 Experience · Dashboard

Three screens, one system

Shared architecture, different resolutions. Each variant optimized for a different physical context — from a lobby kiosk to a work monitor.

What the dashboard shows

Zone tiles — each room has a card with equipment status, temperature, light.
Audio mix — what is playing, where, who has priority (radio / TTS / scene).
Health score — 0–100, viditelný v reálném čase, klesá při problémech.
Brain panel — daily Gemini analysis results + alerts.
TV remote overlay — full controls (D-pad, numpad, Home/Back, channels, volume).
Pomodoro timer — work room, 25/5 cycles with TTS notifications.
Sparkline charts — refrigerator, oven, microwave consumption (120 samples).
Weather — weather + 6h forecast from yr.no (Homey Weather Forecast app, apartment location).

The screenshots above are real shots from the dashboard in operation — same HTML/CSS/JS, different viewports. The live version runs locally via the Homey REST API and is not accessible from the outside — that's by design.

Phase E cache fallback — kiosk 5/14/2026

As of May 14, the RPi kiosk (1024x600 in the lobby) has a smarter way to get data. Instead of hunting directly, Homey now uses REST three-stage fallback chain:

  1. Cache JSON on RPi/HAOS — The Python service on HAOS overwrites a fresh one every minute /local/smart-home/dashboard-data.json from Homey, the kiosk will read it via LAN proxy in a few milliseconds.
  2. Direct Homey REST — if the cache fails, fallback to the classic call /api/manager/logic/variable, will retain the original functionality.
  3. localStorage last-good — if even Homey is unavailable, the kiosk will show the last successfully loaded data + visibly announce that it is old.

A small appeared in the upper right corner of the kiosk badge in one of five colors:

  • ● CACHE — data fresh, everything OK
  • ◐ CACHE OLD — data older than 5 minutes but functional
  • ○ HOMEY — cache failed, read directly from Homey
  • ○ LOCAL — even Homey unavailable, stored values are shown
  • ✕ ERR — all three layers failed

For the user, this means only one thing: the dashboard will never get stuck on a blank screen, even when Homey has a busy moment. And if something is wrong, the badge will say it out loud.
