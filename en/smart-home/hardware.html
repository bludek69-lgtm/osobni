📦 Equipment · Hardware

What is there physically?

What the household is made of: central office, sensors, lights and other equipment. Individual parts were added gradually and each has its own task. Here is an overview of their connections.

Technical details

Hub, sensor network via 4 protocols, 84 devices in 10 zones. Successively layered hardware layers, each with its own role.

Legacy · 2016—2019

Homey Pro (Early 2019)

  • Single-core processor, limited performance
  • Z-Wave + Zigbee + 433 MHz + Wi-Fi + IR
  • Flow-based runtime, limited HomeyScript support
  • Manufacturer supported until EOL

Why it stopped being enough: With the increasing number of flows and the first HomeyScripts, the hub started to have performance problems. Parallel scripts fell on SIGABRT, the runtime could not keep up with real-time events, larger automations blocked the UI. It just wasn't sized for any script-first approach.

Live · current

Homey Pro 2026

Hardware specs

  • CPU: 1.5 GHz Quad-core ARMv8
  • RAM: 4 GB LPDDR4
  • Storage: 8 GB eMMC Flash
  • Updates guaranteed until June 2031

Wireless protocols

  • Wi-Fi 2.4 GHz + 5 GHz
  • Bluetooth Low Energy 5.0
  • Matter v1.3 (controller)
  • Thread (Border Router capability)
  • Zigbee 3.0 (coordinator)
  • Z-Wave 700 Series
  • 433 MHz (legacy sensors)
  • Infrared (TV remote learning)
  • Optional Ethernet adapter (USB-C)

What he can do

  • Local-first processing — cloud only as a backup, automation runs locally
  • Advanced Flow automation (free, no subscription)
  • HomeyScript runtime — full JavaScript for custom scripts
  • REST API with Bearer token for external integrations
  • Satellite Mode — extends range over Homey Bridge
  • Experimental features: SSH access, virtual devices, power user tools

What made it possible: 110+ scripts in parallel without SIGABRT, centralized logic in JavaScript, request-first pipeline, daily Gemini log analysis, real-time dashboards via REST API. Without this leap, the current system would not be possible.

Wireless protocols

Zigbee

The backbone of the sensor network. Sonoff SNZB-06P (mmWave presence), SNZB-03/04 motion + door/window, Aqara P1, IKEA Fyrtur blind, Aqara Cube T1 Pro (6-sided controller).

Z-Wave

Fibaro FGMS multisensor (motion + lux + temperature) in the kitchen, FGS-214 relay for the heating circuit. Slower but more stable for key installations.

Wi-Fi

Xiaomi (Giuseppe robot vacuum cleaner, air purifier, sensors), Shelly Plug S (oven/microwave/refrigerator — power monitoring), Nanoleaf Matter kitchen light bulbs.

Google Cast

Three speakers: Nest Mini Kitchen (primary output), Nest Hub Max Bedroom 2, Nest Mini Bathroom. Plus TTS pipeline with rate limiting to 200 characters.

Key devices

Fyrtur1 roller blind (dining room) — privacy interlock for open space.
Giuseppe (Xiaomi robot vacuum cleaner) — autonomous cleaning with Homey scheduling.
Air Purifier 4 Lite — PM2.5 monitoring + auto mode + alerts.
Android TV bedroom — full integration via com.android.tv:remote (31+ capabilities, native remote).
Aqara Cube T1 Pro — 6-way controller for audio scenes, lights, TV remote.
Raspberry Pi (WaveShare 10.1") — kiosk dashboard 1024×600 + dashboard proxy server on localhost:8080.
