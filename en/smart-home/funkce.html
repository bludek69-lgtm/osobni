🤖 Giuseppe

The vacuum cleaner as an autonomous agent

Xiaomi Viomi V7 robot vacuum cleaner, at home by name Giuseppe (every device has a name, it's friendlier than "vacuum cleaner_01"). Wi-Fi, fixed IP, integrated in Homey via the Mi-Home community app (driver vacuum_viomi_vacuum_v7 verified in Homey API).

Cleaning schedule

  • Schedule: sh_vacuum_router_v1 starts cleaning in the window when no one is home (geofence + phone + scheduler).
  • No interference: if there is motion (real — not fake) in the apartment, the cleaning is postponed. No robot will fly past your feet.
  • Sleep guard: never cleans at night even when it's light sh_spim=yes.
  • Per-zone cleaning: special flow "luxuriate only the kitchen" (after cooking, manual trigger from the dashboard or from the cube).

The token security saga

Pairing Viomi in Homey requires cloud token from Mi Home. The token is session-only — it rotates at every Wi-Fi reconnect, which means that after a router reset / Wi-Fi network change, it must be regained. 5-hour epic saga: factory reset → AP mode (own SSID viomi-vacuum-v8) → discover token → configure_wifi → re-pair in Homey. After that, running stable.

Diagnostics

Battery, mode, last_clean_time, error_code are logged every hour in EventLog. sh_self_healing_v4 has its own detector: if Giuseppe is stuck (battery does not change + mode = error) → alert. Real incident: chair leg caught, robot in dead-loop. Health detect caught it before I did.
