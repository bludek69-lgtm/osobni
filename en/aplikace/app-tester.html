How I use it

  1. I will select the application

    In the configuration I specify the address and pages to check.

  2. I'll run a check

    The tester goes through the pages in the browser and records the progress.

  3. I will review the report

    From the results and screenshots I will find out where to go back with the fix.

Missing evidence means WATCH. The green result is not issued without verification.

If you want to know more

Why was it created and what can it do?

I make my own apps — meal planner, Italy travel planner, ledger, collection, … After each edit, you need to check that all pages still load normally, the console doesn't crash anywhere, and nothing is broken. Clicking through it manually is a pain and it's easy to forget something.

App Tester will do it for me. It starts a browser in the background (without a window), opens each page of the selected application one by one and writes down for each one: did it load at all? how fast are there errors in the browser console? does the page have any content or is it empty? are the pages different from each other (switching works)? He will form a clear verdict from this.

Universal = no hardcode. Applications are not hardcoded — they are in a simple list (config). Adding a new app means adding a few lines: address, list of pages. The tester is generic, it works on anything that runs in a browser.

Same philosophy as Resident Auditor: never PASS without evidence. When the app isn't running, it doesn't get a green or red — it gets a "WATCH" (lack of evidence) so it doesn't produce a false positive. And the tester doesn't change anything — it just looks (read-only), it starts manually, it doesn't run in the background.

Detailed list of features
  • 6 checks for each page — page loading, errors in the console, empty content, loading speed, and whether the pages differ from each other (routing works).
  • Verdict PASS / WATCH / FAIL — FAIL when something doesn't load or the console crashes; WATCH when the page is slow, empty or the app is not running; PASS only if everything is fine.
  • Universal config — add application = one page list object. No code rewriting.
  • Screenshots + report — a snapshot is saved from each page; the result is a clear report by application and a summary for all.
  • No fake PASS — when the app is not running, it is honestly WATCH, not fake green.
  • Manually, read-only — no autorun, just looks, deploys nothing.
