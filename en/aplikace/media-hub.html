If you want to know more

Why was it created and what can it do?

I have a NAS at home full of movies, series, music and home videos — but clicking through network folders to them is no joy. Media Hub is a lightweight, pretty signpost above that: it shows the library as tiles, can search and filter by type, mark "seen" and "favorite" — and runs right next to the TV on a tiny Raspberry Pi.

Just read, won't break anything. Dashboard treats media on the NAS strictly read-only — just goes through them (no deleting, moving or overwriting). It keeps both the "seen/favorite" flags and the index in its own local database (SQLite), never on the NAS.

Secure import from disk to NAS. When I find an old external drive with scattered media, Media Hub first just scans it, sorts the files by type (movies, TV series, music, photos, home videos, documents) and shows plan preview. Only after my confirmation does it copy — and only new files: the source is never deleted, nothing is overwritten on the NAS, everything is verified after the copy. There is always an order scan → draft → preview → confirm → copy → verify.

Covers and descriptions from Jellyfin. Optionally, it connects to my home Jellyfin (running on a NAS) and adds cover, genre, length and description to movies — but it still only reads, it doesn't write anything to Jellyfin or the NAS.

Connected to the smart home. On the TV kiosk, one tap switches between the smart home dashboard and the Media Hub — two interfaces, one screen.

Detailed list of features
  • Library as tiles — movies, series, music, home videos and a separate section of Italian movies; search by name, filter by type, "seen" and "favorites".
  • Read-only over NAS — the only operation on the library is reading; flags and index in local SQLite, never on NAS.
  • Secure import from an external drive — searches the source, sorts by type, shows a preview (dry-run) and copies only after confirmation; only new files, no overwriting, with verification (size + checksum).
  • Jellyfin integration — cover art, genre, length and description from home Jellyfin; purely for display, read-only.
  • Kiosk by the TV — Raspberry Pi in full screen mode, touch switching between smart home and media, automatic library wall.
  • No cloud, just LAN — the whole thing runs on my network, no account, no sending the library out, lightweight core in pure Python.

Availability and current status

Work (work) version v0.2.3 (June 2026). It runs at my home on a Raspberry Pi kiosk next to the TV, reads the library from the NAS. Private, home network (LAN) only, no public hosting and no installer to download — the actual library or personal data does not go to the website. Lightweight core in pure Python (no dependencies), frontend in vanilla JS.
