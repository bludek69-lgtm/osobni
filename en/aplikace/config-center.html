Why was it created and what can it do?

I have about 60 devices at home (lights, motion sensors, thermostatic heads, speakers, cleaner, blind, etc.) controlled by the Homey Pro 2026 system. It can do a lot of things — it has its own mobile app, web interface, scripts, automation — but it has an awful lot of drawers and the settings are scattered.

Config Center unifies it in one place. I open the website in the browser, log in with my own token (the token only stays on my PC, it is not sent anywhere), and I see 22 clear pages: one for each "home mode" (morning / day / evening / night / away / home / sleep), separate heating, separate lights, separate audio, etc. Clicking on the phone is not fun for anyone — here everything can be seen in four columns at once.

Preview mode = safe test. When I want to test something (like a warmer light in the kitchen in the evening), the app first sets it up, gives me 10 minutes to test, and if I don't say "okay, save it" by then, it goes back on its own. So if I accidentally type something stupid, the house will repair itself.

It protects against mistakes. Some devices (audio in the bedroom, sensitive sensors) have a "hard-block" — they cannot be turned on even by mistake if it bothers you. For example, the speaker in the bedroom must not play the test if someone is sleeping there.

Local, own, no cloud. The application is just an HTML+CSS+JS file that opens in Edge or Chrome. It communicates directly with the Homey hub at home, nothing is sent to a foreign server. No subscription, no dependence on the manufacturer's cloud.

Detailed list of features
  • 22 pages for each mode — Morning / day / evening / night / away / home / sleep — I have separate voice messages (TTS), targets for lights, targets for heating for each. I don't have to remember where what is.
  • Heating schedule by days and hours — For each of the 4 zones (dining room, bedroom, bathroom, toilet) day by day, hour by hour what temperature I want. Boost button when I need to heat up quickly.
  • Safe exam with 10 min recovery — Než se změna potvrdí, mám 10 minut na test. Pokud do té doby neřeknu „OK“, samo se to vrátí. You can't break a house with one typo.
  • 100+ things I can tweak — When does the morning routine start, how quickly does the light start (ramp), how long does it take for the audio to turn off, how strong should the briefing be in the morning, ...
  • Token only on my PC, nowhere else — Access to the Homey hub remains only on this computer (in the app and additionally encrypted in the Windows vault to survive reinstallation). No server, no clouds, no "login with Google".
  • Hard-block for sensitive devices — Některá zařízení nemůžou být omylem zapnutá. Třeba audio v ložnici během spánku, čistička přes plíseň, atd.

Development journal
  • v1.9.1 — security clearance (October 2026) — The entire application has undergone a security review and the weaknesses found have been fixed. Auto-update will now only accept a correctly described and newer version, so no one will push it or revert to an older one. Device names and values ​​from the smart home are only displayed as text everywhere, the page has strict protection against sending data elsewhere and cannot be inserted into a foreign page. And the button Save without changes no longer overwrites anything — previously it was able to return the heating settings that someone changed on the panel in the meantime.
  • v1.9.0 — heating even on the panel on the wall (October 2026) — Separate large page Heating on the touch panel: room selection, quick dials Comfort / Night / Exit / Schedule and temperature dial. The manual change is valid until the next transition in the schedule, then the head will return to the schedule by itself. The PC app and the panel share the same control module.
  • v1.8.4–1.8.16 — heating under control (October 2026) — Heating status line: if it is on, if the system wants to heat and if the boiler relay has really switched. Temporary exclusion of the room from the system (1 h / 4 h / 24 h / until further notice). Head cards show when they were last heard from and can permanent Day/Night for an entire week. In addition, AI checks the settings directly in the app, the question "Close without saving?" and more reliable saving (Homey error no longer reports as "Saved").
  • v1.8.3 — settings survive update (September 2026) — Access to Homey is now also kept in the encrypted Windows vault, so reinstallation or updates will not delete it. The update correctly closes and restarts the app.
  • v1.8.0 — standalone installer + new knobs (August 2026) — Config Center can now be installed as a separate app (.exe, like Portfolio Tracker): window + local server, token in localStorage, with silent auto-update (the new version will install itself). 7 previously hidden settings have been added (vacuum cleaner auto-cleaning — time window and min. battery, departure overview, keeping presence in open space, morning radio) and the version is controlled via version.json (SemVer + phase, visible in header).
  • v1.7.5 — Smart Home Hub (May 2026) — 100+ variables editable live from the browser (PC and wall panel): when the morning routine starts, how fast the light starts (ramp), sensor thresholds, time modes and scenes.
  • Voice messages and heating schedule — 22 pages for each mode (morning/day/evening/night/away/home/sleep) and day-by-day, hour-by-hour heating schedule for 4 zones (dining room, bedroom, bathroom, toilet).
  • Safe exam with 10 min recovery — before the change is confirmed, there is 10 minutes per test; if you don't confirm, she will come back on her own. Hard-block for sensitive devices (such as audio in the bedroom during sleep).
  • In private — access to the Homey hub remains only on this PC (app + encrypted Windows safe). No server, no cloud.

Note: the application only runs locally, real data and personal data do not go to the website.
