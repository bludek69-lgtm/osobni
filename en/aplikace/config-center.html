What it does

What it does

I have about 60 devices at home (lights, motion sensors, TRV heads, speakers, air purifier, blind, …) running on Homey Pro 2026. It can do a lot — has its own mobile app, web UI, scripts, automations — but there are far too many drawers and the settings are scattered.

Config Center unifies everything in one place. Open the web in a browser, log in with my token (the token stays only on my PC, nothing is sent anywhere), and see 22 clean pages: one per „house mode“ (morning / day / evening / night / away / home / sleep), separate for heating, lights, audio, etc.

Preview mode = safe test. When I want to try something, the app applies it first, gives me 10 minutes to test, and if I don't say „OK, save it“ in that window, it reverts itself. So even if I make a mistake, the house heals itself.

Protects from mistakes. Some devices (bedroom audio, sensitive sensors) have a hard-block — they cannot be turned on accidentally. The bedroom speaker can't play a test if someone's sleeping there.

Local, mine, no cloud. The app is just an HTML+CSS+JS file opened in Edge or Chrome. It talks directly to the Homey hub at home, nothing goes to a third-party server. No subscription, no vendor cloud dependency.

Key features

Key features

  • 22 pages per mode — Morning / day / evening / night / away / home / sleep — each with its own voice messages (TTS), light goals, heating goals.
  • Per-day, per-hour heating plan — For each of 4 zones (dining, bedroom, bathroom, toilet) day by day, hour by hour what temp I want. Boost button for quick heating.
  • 10-min preview safety — Change applies first, 10 min to test, auto-reverts if I don't confirm. Can't break the house with one typo.
  • 100+ knobs to tune — When morning starts, how fast lights ramp up, how long audio stays on, how loud the morning briefing is, …
  • Token on my PC only — Hub access stays only on this computer (in the app and, encrypted, in the Windows vault so it survives a reinstall). No server, no clouds, no „sign in with Google“.
  • Hard-block for sensitive gear — Some devices can't be accidentally on. E.g. bedroom audio while sleeping, purifier during mold treatment, etc.

Technical notes

📖 Development diary — Config Center

  • v1.9.1 — security review (October 2026) — The whole app went through a security review and the weaknesses found are fixed. Automatic update now accepts only a correctly described and newer version, so nobody can slip one in or roll it back to an older one. Device names and values from the smart home are always shown as plain text, the page has a strict policy against sending data elsewhere and cannot be embedded in another page. And the Save button with no changes no longer overwrites anything — it used to be able to revert a heating setting that someone had meanwhile changed on the panel.
  • v1.9.0 — heating on the wall panel too (October 2026) — A separate large Heating page on the touch panel: room selection, quick choices Comfort / Night / Away / Schedule and a rotary temperature dial. A manual change holds until the next change in the schedule, then the head returns to the plan on its own. The PC app and the panel share the same control module.
  • v1.8.4–1.8.16 — heating under control (October 2026) — A heating status line: whether it is on, whether the system wants to heat and whether the boiler relay really switched. Temporary exclusion of a room from the system (1 h / 4 h / 24 h / until revoked). Head cards show when they last reported in and can store a permanent Day/Night for the whole week. Plus an AI check of the settings right in the app, a “Close without saving?” prompt and more reliable saving (a Homey error is no longer reported as “Saved”).
  • v1.8.3 — settings survive an update (September 2026) — Homey access is now also kept in the encrypted Windows vault, so neither a reinstall nor an update wipes it. The update closes the app properly and starts it again.
  • v1.8.0 — standalone installer + new knobs (August 2026) — Config Center is now installable as a standalone app (.exe, like Portfolio Tracker): a window + local server, token in localStorage, with a silent auto-update (the new version installs itself). 7 previously hidden settings were added (vacuum auto-clean — time window and min. battery, departure digest, holding presence in the open space, morning radio) and the version is driven by version.json (SemVer + stage, visible in the header).
  • v1.7.5 — smart home center (May 2026) — 100+ variables live-editable from the browser (PC and wall panel): when the morning routine starts, how fast the light ramps up, sensor thresholds, time modes and scenes.
  • Voice messages and heating plan — 22 pages, one per mode (morning/day/evening/night/away/home/sleep), and a heating plan day by day, hour by hour for 4 zones (dining room, bedroom, bathroom, toilet).
  • Safe test with a 10-minute revert — Before a change is confirmed there are 10 minutes to test; if you don't confirm, it reverts itself. Hard-block for sensitive devices (e.g. bedroom audio during sleep).
  • Private — Access to the Homey hub stays on this PC only (app + encrypted Windows vault). No server, no cloud.

Note: the app runs locally only; no real data or personal information goes to the web.
