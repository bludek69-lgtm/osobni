If you want to know more

Why was it created and what can it do?

Why it exists: having electricity under control means knowing what takes how much. The app will tell me how much now I take (in W), how much today (in kWh), how much today it stands, how much I expect in a month, and which appliance is drawing the most right now (typically refrigerator, stove, dryer).

How it works: at home I have a small server (Raspberry Pi with Home Assistant) that collects data from a 3-phase meter (Shelly Pro 3EM) and from individual smart sockets. The application asks it every 30 seconds and redraws the values. On PC, it runs as a separate window in Edge — no taskbar, no menus, just a dashboard.

Tariff NT/VT visible: I have a distribution tariff D57D — low tariff (NT, cheap current) in certain hours, high tariff (VT) the rest. The big badge at the top clearly shows which one it is now, and I can then decide whether to start the washing machine.

When the RPi is unavailable (e.g. the internet at home goes down), the application will display the last saved data + a prominent "cached-stale" warning. It never shows fake data as if it is fresh.

Detailed list of features
  • Current consumption in real time — What the house is taking now (W), 3-phase breakdown, top appliance right now. It updates every 30 seconds.
  • Today and month in CZK — How many kWh today, how much it costs (with and without POZE), estimate for the whole month based on the average so far.
  • Tariff NT/VT badge — Visual indication of which tariff is now active — helps to decide when to turn on energy-intensive appliances.
  • Top appliances — Which smart socket is pulling the most right now — useful if you forget something turned on.
  • Heating & boiler — The state of the heating mode, the running time of the boiler for today, if the state agrees with the request.
  • Offline fallback with notification — When the server is unavailable at home, it will show the latest data + a clear message that they are not fresh. Can't be missed.

Development journal
  • v1.0.1 — versions and stages in one place (September 2026) — the number of version and stage (working) is no longer written manually in several places in the header of the dashboard, but is read from one source; before, numbers that did not agree with each other were shown on the screen. At the same time, I disconnected the developer tool for reporting errors from windows. Consumption, prices and tariffs have not changed.
  • v1.0.1 — live house consumption (May 2026) — what the house is currently consuming (W, breakdown after 3 phases, update every 30 s), how many kWh today, price today (with and without POZE) and estimate for the whole month. It hangs on the desktop all day.
  • Tariff and top appliances — badge of the current NT/VT tariff (helps to decide when to turn on energy-intensive appliances), top appliance right now (which outlet draws the most power), heating status and boiler running time for today.
  • Reliably — when the home server is unavailable, it will show the latest data + a clear message that it is not fresh. It is launched with one click from the shortcut on the desktop (Edge app-mode).

Note: the application only runs locally, real data and personal data do not go to the website.
