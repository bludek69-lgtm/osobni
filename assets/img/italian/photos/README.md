# Real photographs for Italian vocabulary

These are actual photographs, not AI-generated images. Source metadata was checked using Wikimedia Commons `imageinfo` / `extmetadata` on 2026-10-10. Attribution, source titles, source links and individual licenses are maintained in `assets/js/italian-data.js`, under `ItalianData.photos`, and shown below each photograph in flashcards and picture quizzes.

Files use the same stable vocabulary IDs as the existing learning module. All 12 photos were visually inspected for the intended subject. The pictures illustrate vocabulary; they are not all taken in Italy (for example, the ticket photograph depicts historical Ugandan railway tickets).

Only Commons-provided JPEG previews (up to 960 pixels wide) or a smaller original were downloaded. No retouching, cropping, generative edits or removal of attribution was performed here. The UI fits the whole image without cropping. Each photograph retains its original individual license; the surrounding application is not relicensed by this collection.
